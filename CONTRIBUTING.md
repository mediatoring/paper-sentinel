# Contributing

Issues and pull requests are welcome.

1. Fork the repository and create a focused branch.
2. Install development dependencies with `pip install -r requirements-dev.txt`.
3. Run `pytest -q` before opening a pull request.
4. Keep the default installation local-first and free of mandatory paid APIs.
5. Do not commit API keys, SMTP passwords, local databases, or downloaded user data.
